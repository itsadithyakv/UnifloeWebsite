## H1: A school LMS connected to everyday school operations

Assignments, learning materials, quizzes, tests, submissions, grading and feedback, connected to the school's classes, people and communication.

## Built around assignments

Faculty create due work for the classes they teach. Students see it in urgency order.

## Connected context

Class, subject, timetable and announcements come from the same school structure.

## Role scoped access

Faculty work within assigned classes. Students see only their own work and feedback.

## Keep teaching and learning connected to the school day

LMS activity sits alongside subjects, sections, faculty assignments and the role inbox, not in a separate portal.

- Assignments, quizzes, tests, essays and materials
- Student submissions and teacher feedback
- Due work, completed work and progress context
- Class and subject aware access controls
## Assessments with server controlled attempts

Attempts are controlled by the server, not the browser, so a retried submission cannot bypass the rules.

- Draft content hidden until published
- Grade, return feedback, release and close
- Live sessions use a realtime channel when configured and an ordinary refresh when it is not
- Authorisation never depends on a live connection
## Use LMS data responsibly

Learning records are private school data and stay inside the school's own space.

- Never on public pages, offline caches or search engines
- Uploads kept in private, per school storage
- Restricted files re authorised on every read
- The installed app uses the same HTTPS API as the browser
